# TESTAMENT — GDD (Game Design Document)

## 0. 프로젝트 정체성

본편 RPG Maker(알만툴)와는 별개 프로젝트. 고아열차 5인 캐릭터·세계관을 빌려서 만드는 Unity 횡스크롤 2D 런앤건 미니게임.
PlayX4 개인 전시 빌드 (카페블루 팀 프로젝트와 별개로 혁 개인 출품).

**한줄 요약:** "AI 천사 집행관들을 피해 열차 위를 달리는 횡스크롤 엔드리스 런앤건."

## 2. 씬 흐름

```
Start → Intro(4컷) → Tutorial(헬 칠판) → CharacterSelect → Game → Result(인서트 코인)
```

### 2-1. Start 씬
- 배경: 열차 위, 헬 머리 날리는 도트 애니메이션 (프레임 2~4장)
- 패럴랙스 3레이어: Layer_Sky(달) / Layer_Cloud(구름) / Layer_City(도시 실루엣)
  - 첫 빌드는 통이미지 정적 배경, 다음 빌드에서 분리
- 입력 시: 두 번 깜빡임 → 암전 → Intro 씬 전환

### 2-2. Intro 씬 (4컷 슬라이드쇼)
| 컷 | 내용 |
|---|---|
| 1 | AI 장악한 도시 전경 |
| 2 | 열차 등장 |
| 3 | 5인 탑승 |
| 4 | 릴이 화면 걷어차기 → 게임으로 강제 전환 |

- 릴 대사: "천재 납셨네 설명이 왜 이렇게 길어"
- any key 스킵 가능
- 아트: NovelAI 생성 → 픽셀라이제이션 후처리

### 2-3. Tutorial 씬
- 헬이 칠판 앞 한석원 교수 포즈로 조작법 가르침
- 표시: WASD / 좌클릭 자동조준 / 우클릭 캐릭터별 특수
- any key → CharacterSelect 전환

### 2-4. CharacterSelect 씬
- 5명 도트 포즈 나란히
- 마우스 호버 → 색상 하이라이트 + 이름 표시 (설명 텍스트 없음)
- 클릭 확정 → SelectedCharacter SO에 기록 → Game 씬 전환

### 2-5. Game 씬
- 시작 시 RAILWAY TO HELL 문구 중앙 슬라이드 인 → 우측 퇴장
- 배경: 횡스크롤 열차 위 루프 (2~3레이어 패럴랙스)
- 플레이어 + AI 동료 4명 동시 달림
- 우상단: 무전기 UI / 좌상단: 거리 스코어 + 피격 횟수
- 적은 오른쪽에서 스폰, 플레이어는 왼→오 방향 진행

### 2-6. Result 씬
- 최종 거리 스코어 표시
- PRESS COIN TO CONTINUE (아케이드 감성)
- 기본 코인 3개 / 코인 소진 → 완전 종료 or Start 씬

## 4. 캐릭터 5종

| 이름 | 컬러 | 좌클릭 | 우클릭 |
|---|---|---|---|
| 헬 (헬레네) | 핑크 | 기관총 연사 + 폭발물 범위딜 | 수동조준 모드 전환 |
| 밀 (미리안) | 노랑 | 리볼버 단발 | 샷건 모드 전환 (홀드 중 근거리 산탄) |
| 루시 | 빨강 | 거리 기준 자동 무기 변환 발사 | 수동 무기 변환 |
| 릴 (리라) | 은발 | 근접 범위 자동 히트 | 가드 + 돌진 / 패링 성공 시 전기톱 강화 |
| 빌 (아비게일) | 파랑 | 홀로그램 해킹툴 발사 (오작동 확률) | 적 해킹 → 적대화 |

### 캐릭터별 특성
- **헬**: 기본형. 폭발 범위딜로 다수 처리. 수동조준으로 원거리 정밀 타격.
- **밀**: 리볼버 단발 기본, 우클릭 홀드로 샷건 전환. 근거리 화력 최강 / 원거리 약함.
- **루시**: 거리 기준 자동 변환 + 우클릭 수동 변환. 고수용.
  - 원거리: 쌍권총 / 중거리: 창 / 근거리: 건틀릿 격투
- **릴**: 근접 범위 자동 히트. 원거리 공격 없음. 패링 성공 시 전기톱 강화 5초. 리스크-리워드형.
- **빌**: 해킹툴 오작동 확률 있음. 강한 적 탱커로 활용하는 전략형/갬블형. 좌클릭 기획 미확정.

### 캐릭터 외형
| 캐릭터 | 외형 |
|---|---|
| 헬 | 방독면 / 핑크 사이드포니 / 블랙 오버사이즈 후드 / 핑크 돌핀팬츠 |
| 밀 | 긴 노랑머리 풀어놓은 것 / 크롭 바람막이 / 카고팬츠 / 펑크 하이탑 |
| 루시 | 어두운 빨강 단발 / 붉은 눈 / 전신 타이즈 + 다크 와인 롱코트 |
| 릴 | 은발 직모 바닥까지 / 흑인 로리 / 오버사이즈 집업 후드 / 워커 / 풍선껌 |
| 빌 | 울프컷 누님 / 찢어진 랩코트 / 다크 네이비 터틀넥 / 블랙 스키니 |

## 5. 루시 무기 3단계

| 거리 | 무기 | 화력 |
|---|---|---|
| 원거리 | 쌍권총 | 최저 |
| 중거리 | 창 | 중간 |
| 근거리 | 건틀릿 격투 | 최고 |

거리 임계값: 인스펙터 변수로 튜닝

## 6. 적: AI 천사 집행관 (7타입)

| 타입 | 특징 | 패턴 |
|---|---|---|
| 기본형 | 기본 창쟁이 기계천사 | 직선 돌진 / 공중 강습 |
| 감시형 | 날개 + 눈알 드론 | 공중 고정 / 유도 없는 미사일 투사체 |
| 방패형 | 정면 방패 | 정면 막기 / 돌진 / 점프 / 측면·상단 약점 |
| 거대형 | 4족보행 미니보스 | 머리·등 약점 / 돌진 / 탄막 / 공중 스톰프 충격파 |
| 탑승형 | 열차 옆면 기어올라옴 | 등장 후 기본형으로 전환 |
| 저격형 | 후방 고정 | 레이저 조준선 → 딜레이 → 레이저 발사 |
| 자폭형 (빨간 드론) | 돌진 후 폭발 | 플레이어 + 동료 전부 피해 |

### 웨이브 구조
- 3웨이브마다 거대형 등장
- 두 번째 거대형 등장 전 고밀도 학살 구간 (의도적 난이도 피크)
- 거대형 등장 예고: 생존 동료가 무전으로 알림 / 전멸 시 예고 없음

### 난이도 곡선
- 초반: 기본형 위주
- 중반: 기본형 + 감시형 + 방패형
- 후반: 저격형·탑승형 추가, 전 타입 혼합 + 고밀도

## 7. HP 시스템

- **플레이어**: 원샷 사망 → 즉시 게임오버
- **AI 동료**: 피격 시 점멸 무적 → 횟수 초과 시 사망 (횟수는 플레이 중 조정)
- **자폭형 폭발**: 플레이어 + 동료 모두 피해

---

## 8. 코인 시스템

- 기본 코인 3개 지급
- 게임오버 시 1개 소모 → 재시작
- 거대형 처치 시 코인 최대 1개 리필
- 코인 소진 → 완전 종료
- 추후 확장: 실물 동전 투입구 USB 키트 연동 (플액 이후)

## 9. 사망 연출

### AI 동료 사망
- 고어 픽셀 파티클
- 무전기 해당 캐릭터 아이콘 지직 → 블랙아웃
- 생존 캐릭터 대사 한마디 (추모 없음)
  - 예시: 릴 사망 시 루시 → "릴 씨 몫의 전기톱이 남아 있습니다. 재분배가 필요합니다."

### 플레이어 사망
- 동일 고어 연출
- 즉시 Result 씬 전환

## 10. 무전기 UI

- 화면 우상단 고정
- 캐릭터 아이콘 5개 (생존 시 점등 / 사망 시 블랙아웃)
- 대사 말풍선 형태 출력

### 대사 출력 트리거
- 랜덤 인터벌 (15~30초)
- 피격 시 리액션
- 적 대량 스폰 시
- 거대형 등장 예고
- 동료 사망 시 고정 대사

### 캐릭터별 무전 대사 톤
| 캐릭터 | 톤 | 예시 |
|---|---|---|
| 헬 | 단어 한마디 또는 침묵 | "피스." / "." |
| 밀 | 괴성 / 욕 / 겁먹은 척 강한 척 | "야 개새끼들 왜 이렇게 많아!!" |
| 루시 | 맥락 없는 진지한 말 | "폭발물 잔량이 쾌적한 수준입니다." |
| 릴 | 짧은 비아냥 | "천재들 왔네." |
| 빌 | 엉뚱한 타이밍에 핵심 정보 | "아 참고로 저 타입 신성 재질이에요 방금 생각남" |

실제 대사 텍스트는 직접 작성

## 11. 캐릭터 목소리 (전자음)

| 캐릭터 | 전자음 톤 |
|---|---|
| 헬 | 낮고 짧은 비프, 거의 무음에 가깝게 |
| 밀 | 높고 거친 노이즈 섞인 톤 |
| 루시 | 깔끔한 합성음, 약간 기계적 |
| 릴 | 날카롭고 짧게 끊기는 톤 |
| 빌 | 지직거리는 노이즈, 불안정하게 |

개발 후반 BGM 작업 시 같이 구현

---

## 12. AI 동료 행동

- 포지션: 플레이어 주변 일정 반경 내, 오프셋 간격 유지하며 겹침 방지
- 사격: 최근접 적 자동
- 별도 전술 없음
- 피격 시 점멸 무적 / 횟수 초과 시 사망
- 총알 파티클 지저분하게 (의도적 연출)

---

## 13. BGM (악기 레이어 시스템)

- 초반: 활기차고 다양한 악기 구성
- 동료 사망마다 악기 하나씩 제거
- 플레이어 혼자 남으면 최소 악기 구성
- 개발 후반 작업

---

## 14. 아트 파이프라인

NovelAI 생성 → 픽셀라이제이션 후처리 (도트 톤으로 변환)

### 작업 순서
1. 스타트 씬 — 헬 머리 날리는 프레임 2~4장 + 배경 3레이어
2. 인트로 씬 — 4컷 일러스트
3. 튜토리얼 씬 — 헬 칠판 포즈
4. 캐릭터 선택 씬 — 5명 도트 포즈
5. 게임 씬 — 플레이어 5종 / 적 7종 도트 애니메이션

### NovelAI 프롬프트 (헬, Start 씬용)
```
1girl, pink hair, side ponytail, gas mask, black oversized hoodie,
pink dolphin shorts, sneakers, standing on top of moving train,
hair blowing in wind, dynamic pose, night sky background,
anime style, full body,
flat color, bold outline, simple shading, high contrast
```

### NovelAI 프롬프트 (배경 루프)
```
train roof, night sky, moving clouds, city lights below,
dystopian cityscape, wide shot, no characters, anime style,
flat color, bold outline, high contrast
```

### 도트 변환 툴
- 변환: monopro.org/pixel/
- 누끼: Aseprite (수동 — 자동 누끼는 픽셀 이미지에서 깔끔하지 않음)
